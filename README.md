## 📱 Overview

**MRTelegram** delivers the genuine Apple iOS liquid physics, Cupertino context menus, Dynamic Island style pill headers, and iOS 18 glass design to Android devices. Built without tracking, advertisements, or background telemetry.

---

## ⚡ Key Features

- **Liquid iOS Physics**: Authentic fluid spring physics, swipe navigation, and Cupertino action sheets.
- **Custom Fonts**: SF Pro Display (iOS 18), Samsung One UI 6, Linotte, and Rubrik Sans.
- **Stealth Reading**: Read messages and explore channel feeds without triggering double-check read receipts.
- **Anti-Delete**: Retain deleted messages and edited histories locally on your device.
- **16x Parallel Turbo Download**: Multi-threaded parallel chunk streaming for rapid file downloads.
- **Local Premium Perks**: High-speed downloads, local reaction badges, and custom aesthetic enhancements.

## 🚀 Installation Guide

1. Download `MRTelegram-V1.0.apk` from the official portal.
2. Tap the APK in your downloads and enable **Install Unknown Apps** if prompted by Android.
3. Open MRTelegram and log in using your phone number and official Telegram security SMS/OTP.
4. Set **Battery Optimization** to **Unrestricted** in *App Info* to prevent Android from delaying background notifications.
